Add the chart repository and check the available version

helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
helm repo update
helm search repo prometheus-community/kube-prometheus-stack

Render values before applying

helm show values prometheus-community/kube-prometheus-stack \
  --version 92.14.1 > /monitoring/kube-prometheus-stack-defaults.yaml
  
rg -n 'retention:|retentionSize:|resources:|storageSpec:|kubeControllerManager:|kubeScheduler:|kubeEtcd:|kubeProxy:' \
/monitoring/kube-prometheus-stack-defaults.yaml

After this we created the dev-vaules file inside "/home/sagar/appln/histdata-modernization-lab/histdata-k8s-deployments/monitoring"

Rendering the values
helm template monitoring prometheus-community/kube-prometheus-stack \
  --version 92.14.1 \
  --namespace monitoring \
  --values values-dev.yaml \
  > /tmp/monitoring-rendered.yaml

Installation 

helm install monitoring prometheus-community/kube-prometheus-stack \
  --version 92.14.1 \
  --namespace monitoring \
  --create-namespace \
  --values values-dev.yaml
  
  
Expose grafana 
    export POD_NAME=$(kubectl --namespace monitoring get pod -l "app.kubernetes.io/name=grafana,app.kubernetes.io/instance=monitoring" -oname)
  kubectl --namespace monitoring port-forward $POD_NAME 3000

Get your grafana admin user password by running:

  kubectl get secret --namespace monitoring -l app.kubernetes.io/component=admin-secret -o jsonpath="{.items[0].data.admin-password}" | base64 --decode ; echo
